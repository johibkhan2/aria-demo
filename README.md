# Aria interactive talking head

A real-time 3D talking head that runs in the browser (WebGL, no dedicated GPU needed). Type a message, get a spoken reply, and watch the face lip-sync using 52 ARKit-style blend shapes.

Built with three.js. Face model: facecap.glb from the three.js examples.

Run locally: `python -m http.server` in this folder, then open http://localhost:8000
